## Website on GitHub Pages (once)

1. Settings > Pages > Build and deployment: Source "Deploy from a branch", branch `main`, folder `/docs`, Save.
2. After a few minutes the site is at https://pdnaeem.github.io/cyclia/ (landing page `docs/index.html`; the
   Markdown documents are published as pages, and `sitemap.xml` is created automatically).
3. Add the site in Google Search Console (URL prefix `https://pdnaeem.github.io/cyclia/`), verify it with the HTML
   tag method in `docs/index.html`, and submit `https://pdnaeem.github.io/cyclia/sitemap.xml`.
4. Put the same address in the About box (Website) and in the Zenodo record (related identifier).

## Discussions (once)

Settings > General > Features: tick **Discussions**. The app's user guide and `SUPPORT.md` link to it.
