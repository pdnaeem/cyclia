# Cyclia 1.4.2

## What is new

- Clearer messages in the app: import warnings, database details and support messages are written for users and
  say what to check first.
- A new website with the documentation: https://pdnaeem.github.io/cyclia/
- New documents: the status of every feature (validated, implemented, partial or planned) and the development
  plan with acceptance criteria.

Calculations are unchanged from 1.4.1.

## Download

Windows: `Cyclia-Setup-1.4.2.exe` · macOS: `.dmg` · Linux: `.AppImage` or `.deb`.
Installed copies of Cyclia update themselves.
