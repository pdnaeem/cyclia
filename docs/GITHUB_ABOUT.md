## Description (max 350 characters)

Free open-source LCA software (ISO 14040/14044) for students, researchers and consultants. No code. Explains results, rates data quality, Monte Carlo and LCC, PEF Circular Footprint Formula, EPD (ISO 14025:2026, EN 15804+A2), ISO 14067 carbon footprint. Works with ecoinvent, ILCD, openLCA and SimaPro data.
