## Description (max 350 characters)

Free open-source LCA software (ISO 14040/14044) for students, researchers and consultants. No code. Explains results, rates data quality, Monte Carlo, LCC, EPD (ISO 14025:2026, EN 15804+A2, programme layouts), ISO 14067, AWARE, LANCA, social LCA and MFA. Works with ecoinvent, ILCD, openLCA and SimaPro data.
