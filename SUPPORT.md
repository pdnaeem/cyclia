# Getting help with Cyclia

| Need | Where |
|---|---|
| How to use a step or a tool | The user guide in the app (Help > User guide) or [docs/USER_GUIDE.md](docs/USER_GUIDE.md) |
| How a result is calculated | [docs/METHODS.md](docs/METHODS.md) |
| Questions, ideas, teaching with Cyclia | [GitHub Discussions](https://github.com/pdnaeem/cyclia/discussions) |
| Something does not work, or a result looks wrong | [Open an issue](https://github.com/pdnaeem/cyclia/issues/new/choose) |
| A security problem | See [SECURITY.md](SECURITY.md) |
| Private support | support@niellosoft.com |

When you report a problem, Help > About > "Export diagnostics for support" creates a file with the error log and
system information. It contains no project data. Please never attach ecoinvent data or other licensed databases.
