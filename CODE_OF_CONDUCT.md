# Code of conduct

Cyclia is a scientific software project. Everyone who takes part, in issues, discussions, pull requests or by
email, is expected to:

- be respectful and constructive, whatever the experience, background or opinion of others;
- criticise ideas, data and code, not people;
- support statements about results with data, references or a reproducible example;
- respect licences: never share ecoinvent data or other licensed content.

Harassment, insults and personal attacks are not accepted. Maintainers may edit or remove such contributions and
block the people who post them.

Report unacceptable behaviour to support@niellosoft.com. Reports are treated confidentially.

This code is based on the principles of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
